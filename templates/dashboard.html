Pruebas de seguridad · comandos de ejemplo
Fuerza bruta / diccionario
Ataque de contraseñas. Bloqueado tras 5 fallos por usuario + 10 por IP en 60s.
for pass in $(cat rockyou.txt); do curl -s -X POST http://localhost:5000/login \ -d "username=admin&password=$pass&totp=000000" sleep 0.1 done
Credential stuffing
Lista de credenciales robadas. Aunque la contraseña sea correcta, el TOTP bloquea.
while IFS=: read u p; do curl -s -X POST http://localhost:5000/login \ -d "username=$u&password=$p&totp=000000" \ -w "\n%{http_code}\n" done < leaked_creds.txt
Password spray
Una misma contraseña probada contra múltiples usuarios. Detección por IP.
for user in admin alice bob carlos; do curl -s -X POST http://localhost:5000/login \ -d "username=$user&password=Winter2025&totp=000000" \ -o /dev/null -w "$user: %{http_code}\n" done
Enumeración de usuarios
Intentar diferenciar usuarios válidos. La respuesta es idéntica siempre.
for user in admin alice bob fake ghost; do curl -s -X POST http://localhost:5000/login \ -d "username=$user&password=x&totp=000000" \ | grep -o "incorrecto\|bloqueado" done
Timing attack
Medir diferencial de tiempo entre usuarios reales y falsos (delay aleatorio).
for user in admin fakeusr999; do time curl -s -X POST http://localhost:5000/login \ -d "username=$user&password=test&totp=000000" > /dev/null done
API de estado y monitoreo
Consultar métricas, IPs bloqueadas, usuarios en lockout y eventos.
curl http://localhost:5000/api/status | python3 -m json.tool # TOTP demo curl http://localhost:5000/api/demo_totp/admin
